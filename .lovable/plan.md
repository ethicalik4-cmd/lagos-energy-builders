# ELATEV Engineering Website

## Scope
Create a premium corporate website for a Lagos-based oil and gas EPC and industrial services company, using ELATEV as the working name from the supplied reference. Build the homepage plus About, Services, and Projects pages, with shared navigation and footer.

## Experience
- Match the reference homepage with a full-viewport offshore construction photo, dark overlay, large serif headline, red calls to action, and restrained top navigation.
- Use real, relevant construction and industrial photography for page sections and project imagery; add refined image hover treatments.
- Add accessible scroll-triggered upward fade reveals for content sections, while respecting reduced-motion preferences.
- Keep claims factual and avoid invented project results, awards, or certifications. Use capabilities-based project profiles unless company-specific project details are supplied.
- Add route-specific titles and social metadata. The contact button will point to an on-page inquiry area until a public email is confirmed.

## Technical approach
- Implement the four pages as TanStack Start routes, with shared site navigation and small reusable reveal behavior.
- Store app photography through the project asset flow; keep styles in the existing Tailwind v4 design system.
- Keep the work frontend-only; no database or external service is required.
- Verify the preview and route metadata, run relevant routing tests, and check the latest build diagnostics.
